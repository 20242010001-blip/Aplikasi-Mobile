# SIAKAD UNIKU Mobile

Layar login React Native untuk Sistem Informasi Akademik UNIKU, dibangun dengan Expo.

## Menjalankan

Pastikan Node.js dan npm sudah terpasang, lalu dari folder proyek jalankan:

```bash
npm install
npx expo install --fix
npm start
```

Pindai QR code menggunakan Expo Go, atau tekan `a` di terminal untuk membuka Android emulator. Untuk iOS, gunakan macOS dengan Xcode.

Form saat ini hanya melakukan validasi input. Integrasi autentikasi memerlukan endpoint/backend kampus.
